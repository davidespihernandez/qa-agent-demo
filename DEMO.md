# Demo script (about 50 minutes)

Work in progress. Outline:

1. **The problem (5 min):** UI-testing agents burn tokens, are opaque, and can use any tool.
2. **Build and run with Astro (15 min):** show a plain-English test, run it locally, deploy.
3. **Put Fabric in front (12 min):** register the LLM and the browser tool, create a gateway key, repoint the agent, run again.
4. **Show the savings (12 min):** the three-arm table (direct / gateway / gateway + Tool Search).
5. **Wrap (6 min):** governance, audit, per-team keys; run the customer's own test.

Fallbacks: a recorded run and screenshots of each arm's results.
